# Pius Shedrach Portfolio

A business-focused web design and development portfolio built with Gatsby, React, and
styled-components.

## Local Development

Use the Node.js version declared in `.nvmrc`, install dependencies, and start Gatsby:

```sh
npm install
npm start
```

## Production Build

Production builds require the canonical site URL:

```sh
SITE_URL=https://your-domain.example npm run build
```

Set `SITE_URL` in Vercel before deploying.

## Content

- Homepage marketing sections live in `src/components/sections`.
- Project case studies live in `content/projects`.
- Future Insights posts belong in `content/posts`.
